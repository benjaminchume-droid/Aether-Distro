# Building Aether

Initial development targets a Linux host with a C toolchain, binutils, x86_64 build tooling, and QEMU.

Milestones:
1. Host-side unit tests
2. Cross-compiled core
3. Kernel/root filesystem assembly
4. Boot image
5. QEMU boot test
6. Real laptop validation

Do not claim hardware support until it has been tested on hardware.
